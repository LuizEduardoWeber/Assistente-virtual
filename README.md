# Assistente-virtual
Códigos para você ter o assistente virtual que estamos montando no TikTok


Para rodar você vai precisar do Wokwi (ele é gratuito e roda no seu navegador)
https://wokwi.com/projects/new/esp32


Para rodar o código do vídeo 1, basta fazer o download dos arquivos biblioteca, rosto.ino e diagram.
Acessar seu wokwi, clicar na seta ao lado de library manager e por fim em upload files e selecionar os arquivos.
